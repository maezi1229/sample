# 見積書作成 自動化ツール 運用ガイド

仕入先PDF見積を読み取り→自社Excel見積書テンプレートへ転記→利益上乗せ計算→PDF化、
までを自動化するツールです。客先へのメール送付は対象外（引き続き手動）です。

Excelアプリは一切起動しません（COM操作・マクロ不使用）。PythonとLibreOffice
（無料の別ソフト。数式の再計算とPDF変換にのみ使用）で完結します。

---

## 0. 一度だけ行う準備（IT担当・詳しい人向け）

日々の運用を始める前に、1回だけ以下のインストールが必要です。

1. **Python** をインストール（<https://www.python.org/> からWindows版）
   - インストール時に「Add python.exe to PATH」に必ずチェックを入れる
2. コマンドプロンプトで、このフォルダに移動して依存ライブラリを入れる
   ```
   cd quote_automation
   py -3 -m pip install -r requirements.txt
   ```
3. **Tesseract OCR**（日本語データ込み）をインストール
   - <https://github.com/UB-Mannheim/tesseract/wiki> のWindows版installerを使用
   - インストール時に「Additional language data」→「Japanese」を選択
   - インストール後、`quote_automation/config.py` の `TESSERACT_CMD` に
     インストール先の `tesseract.exe` のフルパスを設定する
     （例: `r"C:\Program Files\Tesseract-OCR\tesseract.exe"`）
4. **LibreOffice** をインストール（<https://ja.libreoffice.org/download/>）
   - 数式の再計算チェックとPDF変換にのみ使用。文書編集には使わない
5. `quote_automation/config.py` の `LOCAL_WORK_DIR` を、**Box同期フォルダの外**にある
   ローカルフォルダに変更する（例: `Path(r"C:\Users\自分の名前\quote_work")`）
6. `quote_automation` フォルダ一式をPC内の分かりやすい場所にコピーする
   （Box同期フォルダの中でも構いませんが、`LOCAL_WORK_DIR` だけは必ずBoxの外にすること）

ここまでできれば、以降は次の「日々の運用」だけで使えます。

---

## 1. 事前にやっておくこと（案件ごと・手動）

このツールは仕入先PDFに書かれていない情報（客先名・部署・担当者名・件名・
支払条件・備考など）は転記しません。**案件用のExcel見積書テンプレートに、
あらかじめこれらを入力しておいてください。**（これは今回の自動化の対象外です）

---

## 2. 日々の運用（2ステップ）

`quote_automation` フォルダの中にある2つのファイルをダブルクリックするだけです。

### ① `1_仕入先PDFを読み取る.bat`

1. ダブルクリックすると、ファイル選択画面が開く
2. 仕入先から届いたPDF見積を選ぶ
3. 少し待つと「確認用シート（レビューシート）」ができ、自動でExcelが開く
4. **必ず元のPDFと見比べながら、レビューシートのC列（確定値）と明細
   （品名・数量・単価）を確認・修正してから上書き保存する**
   - OCR（機械読み取り）は完璧ではありません。特に金額と数量は必ず目視確認してください
   - 数量が空欄のままだと次のステップでエラーになります（安全装置です）

### ② `2_見積書を作成する.bat`

1. ダブルクリックすると、ファイル選択画面が2回開く
   - 1回目: ①で確認・修正したレビューシート(xlsx)を選ぶ
   - 2回目: この案件用に客先名等を入力済みのExcel見積書テンプレートを選ぶ
2. 自動で「転記→利益計算の検証→PDF化」が行われる
3. 完成したPDFが自動で開くので、内容を確認する
4. 問題なければ、**これまで通り手動で**客先へメール送付する

途中でエラーメッセージが出た場合は、指示された内容（宛先未入力、数量未確認、
計算結果の不一致など）を確認して、レビューシートやテンプレートを直してから
もう一度実行してください。

---

## 3. 制限事項・注意点

- 明細は1見積につき最大3件までです（テンプレートの行数に合わせています）
- 利益率はテンプレートの `M17` セル（現在1.09＝9%上乗せ）で管理されています。
  率を変える場合はテンプレート側のM17を編集してください（Python側は変更不要）
- 仕入先ごとにPDFのレイアウトが異なるため、OCRでの自動読み取り精度は
  仕入先によってばらつきます。**レビューシートでの確認は毎回省略しないでください**
- 運賃を明細と別に立てたい場合など、現状のテンプレート構成から外れるケースは
  別途相談してください
